## Goal

Add a chat pane Obsidian sidebar view that displays a simple conversational interface with message bubbles, accepting user input and returning a canned "under development" response — serving as the UI entry point for the agentic RAG feature.

## Requirements

### Functional Requirements

| ID | Requirement | Notes |
|----|-------------|-------|
| FR-01 | The plugin must register a custom Obsidian View (`ChatViewType` constant) that renders a chat pane in the sidebar. | Registered in `onload()`, unregistered in `onunload()`. |
| FR-02 | The chat pane must be toggleable via a ribbon icon. | Ribbon icon registered in `onload()`, removed in `onunload()`. |
| FR-03 | The chat pane must be invocable via a command palette command. | Command registered in `onload()`, removed in `onunload()`. |
| FR-04 | The chat pane must display a message input field (text input + send button or Enter to send). | Input field at the bottom of the pane. |
| FR-05 | When the user sends a message, it must appear as a bubble aligned to the right side of the chat area. | User message bubble. |
| FR-06 | After the user sends a message, a canned response ("This functionality is under development") must appear as a bubble aligned to the left side. | Assistant message bubble. |
| FR-07 | Messages must accumulate within the session — each new message is appended below previous ones. | Messages are not persisted across plugin reloads or Obsidian restarts. |
| FR-08 | The chat area must auto-scroll to the newest message when a new message pair is added. | Scroll to bottom after each send. |
| FR-09 | The input field must be disabled while the canned response is being rendered (no double-send). | Prevents multiple rapid sends; trivial since response is synchronous. |
| FR-10 | The input field must be cleared after the message is sent. | UX polish. |

### Non-Functional Requirements

| ID | Requirement | Notes |
|----|-------------|-------|
| NFR-01 | The chat pane must follow existing Obsidian plugin UI patterns (CSS classes, theming) used elsewhere in the plugin. | Reuse styles from `reindex-confirmation-modal.ts` and existing components. |
| NFR-02 | The chat pane must not depend on any backend RAG services — it is purely a UI stub. | No network calls, no embedding calls, no vector store interaction. |
| NFR-03 | The canned response text is hardcoded. | No settings integration required for this iteration. |

## Scope

### In-scope
- Custom Obsidian View implementation (`ChatView`)
- Ribbon icon registration for toggling the view
- Command palette registration
- Chat UI with message input field and send button
- Message bubble rendering (user right, assistant left)
- Auto-scroll to newest message
- Session-only message accumulation (no persistence)
- Canned response display
- Per-message copy button (⌘ symbol, hidden by default, shown on hover, copies to clipboard)

### Out-of-scope
- Actual RAG query processing (no LLM/embedding/vector store calls)
- Message persistence across sessions
- Configurable canned response text
- Markdown rendering in messages
- Image/file attachments
- Multi-turn context (no conversation history sent anywhere)
- Typing indicators or streaming responses
- Settings UI for chat-specific options
- Dark/light theme customization beyond Obsidian defaults

## Context

This feature is the first user-facing UI component for the agentic RAG pipeline. PRD 001.01 covers the RAG indexing pipeline (chunking, embedding, vector store), and PRD 001.02 covers incremental change handling. The chat pane will eventually connect to that backend, but for now it is a pure UI stub.

Existing UI patterns in the plugin:
- `src/ui/reindex-confirmation-modal.ts` — a modal confirmation dialog for reindexing
- `src/ui/components/` — existing UI components directory

The chat pane should be placed in `src/ui/` alongside the existing modal and components, likely as `src/ui/chat-view.ts`.

### Architecture

```
src/ui/chat-view.ts
├── CHAT_VIEW_TYPE constant (unique string identifier)
├── CANNED_RESPONSE constant ("This functionality is under development")
└── ChatView extends ItemView
    ├── getViewType(): string → returns CHAT_VIEW_TYPE
    ├── getDisplayText(): string → returns "Chat"
    ├── getIcon(): string → "message-square" (Lucide icon)
    ├── onOpen(): Promise<void> → build DOM with setCssStyles: chat container + message list + input row + auto-focus
    ├── onClose(): Promise<void> → clean up DOM references (only #messageListEl tracked)
    ├── #renderMessage(text: string, sender: "user" | "assistant"): void → append bubble wrapped in row div with hover copy button
    ├── #onSend(inputEl: HTMLInputElement): void → handle user message submission, retain focus after send
    └── #scrollToBottom(): void → auto-scroll message area
```

### ChatView Class Details

```typescript
import type { WorkspaceLeaf } from "obsidian";
import { ItemView } from "obsidian";

export const CHAT_VIEW_TYPE = "yggdrasil-chat";
export const CANNED_RESPONSE = "This functionality is under development";

export class ChatView extends ItemView {
  #messageListEl: HTMLElement | null = null;

  public constructor(leaf: WorkspaceLeaf) {
    super(leaf);
  }

  public getViewType(): string {
    return CHAT_VIEW_TYPE;
  }

  public getDisplayText(): string {
    return "Chat";
  }

  public getIcon(): string {
    return "message-square";
  }

  public async onOpen(): Promise<void> {
    const { contentEl } = this;
    contentEl.addClass("yggdrasil-chat-view");

    // Set root container styles
    contentEl.setCssStyles({
      display: "flex",
      flexDirection: "column",
      height: "100%",
    });

    // Chat message list area
    const listEl: HTMLElement = contentEl.createDiv({ cls: "yggdrasil-chat-messages" });
    listEl.setCssStyles({
      flex: "1",
      overflowY: "auto",
      padding: "12px 16px",
      display: "flex",
      flexDirection: "column",
      gap: "8px",
    });
    this.#messageListEl = listEl;

    // Input row at bottom
    const inputRow: HTMLElement = contentEl.createDiv({ cls: "yggdrasil-chat-input-row" });
    inputRow.setCssStyles({
      display: "flex",
      gap: "4px",
      padding: "8px",
      backgroundColor: "var(--background-primary)",
      borderTop: "1px solid var(--background-modifier-border)",
      flexWrap: "wrap",
    });

    const input: HTMLInputElement = inputRow.createEl("input", {
      type: "text",
      cls: "yggdrasil-chat-input",
      placeholder: "Type a message…",
    });
    input.setCssStyles({
      flex: "1",
      marginBottom: "0",
      marginTop: "0",
    });

    const sendBtn: HTMLElement = inputRow.createEl("button", {
      text: "Send",
      cls: "mod-cta",
    });
    sendBtn.setCssStyles({
      flexShrink: "0",
      marginBottom: "0",
      marginTop: "0",
      padding: "6px 12px",
    });

    input.addEventListener("keydown", (evt: KeyboardEvent): void => {
      if (evt.key === "Enter" && !evt.shiftKey) {
        evt.preventDefault();
        this.#onSend(input);
      }
    });

    sendBtn.addEventListener("click", (): void => {
      this.#onSend(input);
    });

    // Focus input when pane first opens — defer until after render
    setTimeout(() => {
      input.focus();
    }, 0, 0);
  }

  public async onClose(): Promise<void> {
    this.#messageListEl = null;
  }

  #onSend(inputEl: HTMLInputElement): void {
    const text: string = inputEl.value.trim();
    if (text.length === 0) {
      return;
    }

    // Disable input while rendering canned response
    inputEl.disabled = true;
    try {
      // Append user bubble
      this.#renderMessage(text, "user");

      // Clear input
      inputEl.value = "";

      // Append assistant bubble (canned response)
      this.#renderMessage(CANNED_RESPONSE, "assistant");

      // Auto-scroll
      this.#scrollToBottom();
    } finally {
      // Re-enable input regardless of outcome
      inputEl.disabled = false;
      // Retain focus for quick follow-up messages
      inputEl.focus();
    }
  }

  #renderMessage(text: string, sender: "user" | "assistant"): void {
    if (this.#messageListEl === null) {
      return;
    }

    // Wrapper row: [copy button] [bubble content]
    const wrapper: HTMLElement = this.#messageListEl.createDiv({
      cls: `yggdrasil-chat-row yggdrasil-chat-row--${sender}`,
    });
    wrapper.setCssStyles({
      display: "flex",
      flexDirection: sender === "user" ? "row-reverse" : "row",
      gap: "6px",
      alignItems: "flex-start",
    });

    // Copy button — hidden by default, shown on hover
    const copyBtn: HTMLButtonElement = wrapper.createEl("button", {
      cls: "yggdrasil-chat-copy-btn",
      attr: { title: "Copy message" },
    });
    copyBtn.textContent = "\u2398"; // ⌘ symbol as copy icon
    copyBtn.setCssStyles({
      width: "20px",
      height: "20px",
      display: "flex",
      alignItems: "center",
      justifyContent: "center",
      fontSize: "12px",
      backgroundColor: "transparent",
      border: "none",
      cursor: "pointer",
      opacity: "0",
      transition: "opacity 0.15s ease",
      padding: "0",
      flexShrink: "0",
    });

    // The actual message bubble
    const bubble: HTMLElement = wrapper.createDiv({
      cls: `yggdrasil-chat-bubble yggdrasil-chat-bubble--${sender}`,
    });

    // Style the bubble based on sender
    if (sender === "user") {
      bubble.setCssStyles({
        backgroundColor: "var(--interactive-accent)",
        color: "var(--text-on-accent)",
        borderRadius: "12px",
        padding: "8px 12px",
        fontSize: "var(--font-text)",
        lineHeight: "1.4",
      });
      copyBtn.setCssStyles({
        color: "var(--text-on-accent)",
      });
    } else {
      bubble.setCssStyles({
        backgroundColor: "var(--background-modifier-hover)",
        color: "var(--text-normal)",
        borderRadius: "12px",
        padding: "8px 12px",
        fontSize: "var(--font-text)",
        lineHeight: "1.4",
        border: "1px solid var(--background-modifier-border)",
      });
      copyBtn.setCssStyles({
        color: "var(--text-muted)",
      });
    }

    // Show/hide copy button on hover
    wrapper.addEventListener("mouseenter", (): void => {
      copyBtn.style.opacity = "1";
    });
    wrapper.addEventListener("mouseleave", (): void => {
      copyBtn.style.opacity = "0";
    });

    // Copy on click
    copyBtn.addEventListener("click", (evt: MouseEvent): void => {
      evt.stopPropagation();
      navigator.clipboard.writeText(text).then(() => {
        // Brief visual feedback
        copyBtn.textContent = "\u2713"; // ✓ checkmark
        setTimeout(() => {
          copyBtn.textContent = "\u2398";
        }, 1000);
      });
    });

    const contentEl = bubble.createEl("div", {
      cls: "yggdrasil-chat-bubble-content",
      text,
    });
    contentEl.setCssStyles({
      wordWrap: "break-word",
      whiteSpace: "pre-wrap",
      userSelect: "text",
    });

    this.#scrollToBottom();
  }

  #scrollToBottom(): void {
    if (this.#messageListEl === null) {
      return;
    }

    this.#messageListEl.scrollTop = this.#messageListEl.scrollHeight;
  }
}
```

### main.ts Integration

In `onload()`, after existing registrations:
```typescript
import { CHAT_VIEW_TYPE, ChatView } from "./ui/chat-view";

// Register chat view
this.registerView(CHAT_VIEW_TYPE, (leaf: WorkspaceLeaf) => new ChatView(leaf));

const openChat = (): void => {
  const leaves: Array<WorkspaceLeaf> = this.app.workspace.getLeavesOfType(CHAT_VIEW_TYPE);
  if (leaves.length > 0) {
    // Reveal existing leaf (handles minimized/collapsed panes correctly)
    this.app.workspace.revealLeaf(leaves[0]);
  } else {
    const leaf: WorkspaceLeaf | null = this.app.workspace.getRightLeaf(false);
    if (leaf !== null) {
      leaf.setViewState({ type: CHAT_VIEW_TYPE });
      this.app.workspace.revealLeaf(leaf);
    }
  }
};

// Chat ribbon icon
this.addRibbonIcon("message-square", "Open Chat", openChat);

// Command palette entry
this.addCommand({
  id: "open-chat",
  name: "Open Chat",
  callback: openChat,
});
```

In `onunload()`:
```typescript
const chatLeaves: Array<WorkspaceLeaf> = this.app.workspace.getLeavesOfType(CHAT_VIEW_TYPE);
chatLeaves.forEach((leaf: WorkspaceLeaf): void => {
  leaf.detach();
});
```

### DOM Structure & CSS Classes

The chat view uses a flexbox layout with inline styles via `setCssStyles()` — no separate CSS file is needed. The styling uses Obsidian's native design tokens (`--interactive-accent`, `--background-modifier-hover`, `--background-modifier-border`, `--background-primary`, `--font-text`, `--text-on-accent`, `--text-normal`, `--text-muted`) for theme compatibility.

Each message row is wrapped in a `yggdrasil-chat-row` div that positions the bubble and a hidden copy button. The copy button (⌘ symbol) is shown on hover via `mouseenter`/`mouseleave` event listeners and copies the message text to clipboard via `navigator.clipboard.writeText`.
